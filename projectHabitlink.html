Overview

HabitLink is a physical product that also communicates with an individual website to help users track their habits and progres with a friend. This project was created for MinneHack 2026, a hackathon hosted by the University of Minnesota.The prompt for this project was "mending over endeing", and our take on this was to create a product that would help users mend their habits. Adding a partner to the tracker allows for accountability and support, which is a key factor in habit formation. The physical product is a small device that can be placed in a visible location, such as on a desk or nightstand, to serve as a reminder to complete the habit. The website allows users to log their progress and communicate with their partner about their habits.

This project was made in a 24 hour period using an ESP32 microcontroller, a proton microcontroller, and buttons and LEDs all wired onto a breadboard. The website was hosted through the ESP32, and was written in HTML, CSS, and JavaScript. The website showed visually how far a user has progressed with their task by showing a progress bar that was updated when the user pressed the button on the physical device. All firmware was written in C++ using the Arduino IDE. The physical device and website communicated with each other through the ESP32's WiFi capabilities, allowing for real-time updates on the user's progress.
