Overview

This project was the final for EE2361 - Introduction to Microcontrollers. This was a very open-ended project that allowed us complete creativity in our design, so our group chose to explore animatronics deeper, creating two eyes that move autonomously. The movement was controlled by a PIC24 microcontroller and two servo motors, and wether or not movement occoured was based on light levels from a photoresistor. The eyes were 3D printed, and attatched to the eyes for a more realistic look. Additionally, the eyes could be controlled manually using a keypad when the light levels were low and were able to be set to any position in degrees. The position that the eyes were set to was stored and displayed on an LCD 7-segment display.

My Role

This project was done in groups of four, I was mainly responsible for dealing with the code for the photoresistor, and assisted with the code for the keypad and LCD display. The code for this project was written in a combonation of C and Assembly, and is found on my Github!

Technical Details

  • Tools: PIC24 Microcontroller, Servo Motors, Photoresistor, Keypad, LCD 7-Segment Display
  • Concepts: Embedded Systems, C Programming, Assembly Language, Sensor Integration
  • Impact: Developed skills in microcontroller programming and embedded systems design.
